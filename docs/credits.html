PROJECT NOTES

Credits & provenance

The research content follows Towards Generalist Game Players and its revised survey. The living collection is maintained in Awesome-LFMs-Play-Games.

The editorial visual direction was inspired by the AI for Games in the Foundation Model Era project page. This page uses an independently implemented layout, original text, original diagrams, and an original player-centered concept image. It does not reuse that project's artwork, videos, or code.

The cover artwork was generated with OpenAI's built-in image-generation tool for this project. It is conceptual artwork, not a screenshot or an empirical result. Its prompt and file details are documented in the asset notes.

The video overview uses original project artwork, animation, music, and synthetic narration to illustrate the survey. See the asset notes for sources.

The transfer lab is a deterministic teaching illustration. Its fixed route and breadth-first search planner are scripted; it does not run a foundation model or report model benchmark results.

Typography uses DM Sans and Space Grotesk via Google Fonts, with system fallbacks. Linked papers, project resources, and third-party media remain attributed to their respective creators.

The website's 210-resource catalog is derived from the repository reading list, including related surveys. The 32-work October supplement is separately tracked with source and availability notes. This total is not the manuscript's bibliography count.
