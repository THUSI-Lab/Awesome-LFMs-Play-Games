# Original project assets

- `player-worlds.png`: original conceptual hero artwork generated for this project with the built-in OpenAI image-generation tool. It is not a game screenshot or a model evaluation result.
- `mark.svg`: original vector player mark implemented in SVG.
- `repository-banner.svg`: original vector repository cover.

The artwork is designed around a player entering different interactive worlds. No artwork, video, logo, or implementation from the reference project was reused.

## Project film

The 90-second project film uses the original cover artwork and eight scenes of original Canvas animation to explain player capabilities, learning environments, and evaluation. The visuals are conceptual illustrations, not gameplay recordings or model performance results.

- [`../media/generalist-game-players-v2.mp4`](../media/generalist-game-players-v2.mp4): final video with English narration and an original synthesized musical score.
- [`../media/poster.png`](../media/poster.png): poster for the film.
- [`../media/subtitles.en-zh.srt`](../media/subtitles.en-zh.srt): English and Chinese subtitles aligned to the final narration.

The narration is a continuous synthetic English performance using the **Benjamin** voice, generated through **Runway** with the `eleven_v3` model. The source narration lasts 87.76 seconds; it was not assembled by cutting individual sentences. No real person's voice was cloned for this project. Subtitle timings follow the final spoken performance.

The score is original synthesized music created for this film. The production uses original graphics and the project artwork rather than footage, audio, or code from the reference survey. The film presents research concepts and aspirations; it does not claim that the illustrated players are running foundation models or achieving measured benchmark results.

## Hero prompt

Use case: stylized-concept. Asset type: original widescreen hero artwork for an academic project page about generalist AI game players. Scene: a small capable ivory-and-graphite robot player with a simple amber visor, viewed from behind three-quarter angle, standing on a slate platform in the foreground and considering three distinct playable worlds arranged as tall luminous portal-like windows across the middle and right: a lush blocky exploration world with a lake and mountains, a geometric platforming course with stepping platforms, and a precise strategy board with abstract chess-like pieces. A fine warm amber path connects the player's route between worlds, representing experience and transfer. Strong readable silhouette, believable miniature environments, sophisticated cinematic 3D editorial concept art with fine material detail, muted cyan and warm copper highlights against deep ink #10141b. Landscape 16:9, composition weighted to the RIGHT two thirds, left third mostly very dark negative space for HTML text. Player is the protagonist; environments are places to act and learn. Atmospheric depth and crisp focal details, restrained bloom, premium research-publication cover quality. No castles, no fantasy city, no UI screens, no text, no letters, no logos, no graphs, no watermarks, no construction or game-building tools.
